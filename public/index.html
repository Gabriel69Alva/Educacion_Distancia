Escenarios Interactivos

Unidad 2

  • 2.1. Axiomas de campo

    Se muestra el funcionamiento de los axiomas de orden y campo posicionando puntos o valores en la recta real.

  • 2.2. Caracterización del supremo

    Se muestra cómo aplicar la caracterización del supremo a un conjunto específico. Posteriormente, se demuestra la equivalencia del supremo y la caracterización.

Unidad 3

  • 3.1. Gráficas funciones pares e impares

    Se aborda la relación entre las funciones pares e impares con sus respectivas simetrías. Se presenta dos ejemplos en donde se demuestra la paridad y la imparidad de dos funciones polinomiales, respectivamente.

  • 3.2. Función par e impar

    Se estudian las funciones pares e impares con sus respectivas definiciones. Se demuestra que el producto de una función par por una impar es impar, y que la suma de pares es par.

  • 3.3. Grafica de una función inyectiva

    Se estudia el concepto de función inyectiva mediante un acercamiento geométrico y algebraico. Posteriormente, se formaliza el concepto y se demuestra la inyectividad de una recta y la no inyectividad de una parábola.

  • 3.4. Diagrama de una función inyectiva

    Se estudia el concepto de función inyectiva mediante diagramas de Venn y su definición algebraica. Posteriormente, se formaliza el concepto y se demuestra la inyectividad de una función racional y la inyectividad de la composición de funciones inyectivas.

  • 3.5. Gráfica de una función suprayectiva

    Se estudia el concepto de función sobreyectiva mediante un acercamiento geométrico y algebraico. Posteriormente, se formaliza el concepto y se presenta un ejemplo de cómo demostrar que una función es sobreyectiva.

  • 3.6. Diagrama de una función suprayectiva

    Se estudia el concepto de función sobreyectiva mediante diagramas de Venn y de manera algebraica. Posteriormente, se presenta un ejemplo de dos funciones sobreyectivas cuya suma no es sobreyectiva.

  • 3.7. Cuestionario sobre funciones, V1

    Se repasan los conceptos de función par, impar, inyectiva, sobreyectiva y biyectiva mediante sus definiciones.

Unidad 4

  • 4.1. Monotonía completa diagramas

    Se aborda la definición de sucesión creciente, decreciente y estrictamente creciente y decreciente mediante diagramas de Venn. Posteriormente, se presenta un ejemplo de cómo demostrar que una sucesión es estrictamente creciente.

  • 4.2. Límite de una sucesión proceso formal

    Se aborda la definición (épsilon-N) del límite de una sucesión de números reales generada de manera aleatoria. El acercamiento se realiza de manera geométrica y aritmética.

Unidad 5

  • 5.1. Límite proceso intuitivo

    Se aborda la definición (épsilon-delta) del límite de una función en un punto dado. El acercamiento se realiza de manera geométrica en funciones generadas aleatoriamente. La idea es dada épsilon construir una vecindad delta que cumpla la definición “informal” del límite de una función en un punto dado.

  • 5.2. Límite proceso formal

    Se aborda la definición (épsilon-delta) del límite de una función en un punto dado. El acercamiento se realiza de manera geométrica y aritmética : El caso de una recta.

  • 5.3. Límite proceso formal con acotación de delta

    Se aborda la definición (épsilon-delta) del límite de una función en un punto dado. El acercamiento se realiza de manera geométrica y aritmética : El caso de una parábola.

Unidad 6

  • 6.1. Continuidad

    Se analiza la gráfica de funciones definidas por pedazos. Se describen tres tipos de discontinuidades: de salto, evitable y discontinuidad infinita.

  • 6.2. Conjunto negativo

    Estudia de forma geométrica cuándo una función es negativa.

  • 6.3. Teorema de conservación del signo

    Este escenario permite visualizar conceptos involucrados en la ley de la conservación del signo. Posteriormente se formula y se demuestra este teorema.

  • 6.4. Teorema del valor intermedio

    Este escenario permite visualizar conceptos involucrados en el teorema del Valor Intermedio. Posteriormente se formula el teorema mediante una conjetura y finalmente se demuestra este teorema.

  • 6.5. Contradicción con el supremo

    Este escenario permite visualizar conceptos involucrados en un paso clave en una demostración por contradicción del Teorema del Valor Intermedio. Se analiza el Caso 1.

  • 6.6. Teorema de Weierstrass

    Este escenario permite visualizar conceptos involucrados en el teorema de Weierstrass. Posteriormente se formula el teorema mediante una conjetura y finalmente se demuestra.

Unidad 7

  • 7.1. Derivada

    Se estudia un acercamiento a la derivada de una función en un punto a través de la recta tangente a la gráfica

  • 7.2. Teorema de Fermat

    Este escenario permite visualizar conceptos involucrados en el teorema de Fermat. Posteriormente se formula el teorema mediante una conjetura y finalmente se demuestra.

  • 7.3. Teorema de Rolle

    Este escenario permite visualizar conceptos involucrados en el teorema de Rolle. Posteriormente se formula el teorema mediante una conjetura y finalmente se demuestra.

  • 7.4. Teorema del valor medio

    Este escenario permite visualizar conceptos involucrados en el teorema del Valor Medio. Posteriormente se formula el teorema mediante una conjetura y finalmente se demuestra.

Unidad 8

  • 8.1. Análisis de gráficas

    La primera y segunda derivada nos revelan la "anatomía" de la gráfica de una función: sus picos, valles y cambios de concavidad.

  • 8.2. Modelo de dieta

    Explora cómo las calorías consumidas en un tiempo determinado determinan el límite de tu peso mediante el modelo matemático: $W(n)=\frac{c}{40}+(W_{0}-\frac{c}{40})e^{-0.0052n}$
